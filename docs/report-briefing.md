# 일간·주간 브리핑

## 참고 사례

- [SANS NewsBites](https://www.sans.org/newsletters/newsbites/xxviii-73): 주요 이슈, 사실 요약, 편집자 해석, 관련 원문을 연결한다.
- [Cisco Talos Threat Source](https://blog.talosintelligence.com/give-yourself-room-to-be-human/): 핵심 사안, 중요한 이유, 다음 행동을 연결하고 주간 기사와 연구를 별도로 제공한다.

외부 자료의 본문을 복제하지 않고 정보 구성만 참고한다. 보고서 내용은 해당 집계 기간의 공개 수집 자료로 생성한다.

## 적용 구성

일간은 총평과 우선 확인할 이슈 최대 3건, 주간은 총평과 전주 대비 언급량 변화 및 핵심 이슈 최대 3건을 제공한다. 이슈별 요약 바로 아래에 권고 조치를 배치하고 관련 원문은 접어 둔다. 추가 참고 기사는 최대 4건이며 수집 통계는 하단에서 펼칠 수 있다.

기존 한국어 원문 형식인 `[총평]`, `[핵심 위협 TOP 3]`, `[권고 조치]`는 보존한다. 새 `briefing` 필드는 같은 생성 입력의 이슈와 조치를 결합한다. 구버전 보고서는 당시 카드 순서로만 연결하며 새 후보에 과거 요약을 재배치하지 않는다.

## 선정·검증

- 공개된 교차 확인 카드와 P1/P2 기사에서 후보를 선정한다. 비CVE P1 캠페인이 CVE 카드에 밀려 누락되지 않도록 한다.
- 추적 URL을 원문 URL로 정규화하고 동일 기사·요약·소수 CVE 중복을 제거한다.
- 내부 보유 자산·PIR는 모델 입력과 공개 브리핑에서 제외한다.
- 항목 수 불일치, 동일 항목 반복, 빈 Issues 안내, 다른 이슈의 CVE, 일반적인 조치 문구를 검사한다.
- 실패 시 잘못된 문장을 발행하지 않고 원문 요약과 재생성 상태를 표시한다.
- 주간 언급량은 수집된 기록의 집계다. 실제 공격 수나 신규 캠페인 수로 표현하지 않는다.

정규식 검사는 사실성 전체를 증명하지 못한다. 특히 기존 CVE 묶음의 영향 버전·악용 상태는 원자료 수준에서 추가 검증이 필요하다. 변경 작업은 과거 보고서 전체를 재생성하지 않는다.
